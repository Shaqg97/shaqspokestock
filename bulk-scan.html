CSV export notes

The CSV is a generic listing-preparation sheet with titles, quantity, asking price, condition, SKU and notes. It is not yet certified as a direct eBay Seller Hub bulk-upload template; eBay templates and required fields can change. Review the exported columns against the current eBay AU template before uploading.

No paid services or API keys are required. The catalogue lookup uses the public TCGdex API when you choose to search; if it is unavailable, edit the row manually.
