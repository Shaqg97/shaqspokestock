What “fresh stock checks” means
Only retailer listings successfully checked and matched to the correct product within the last 30 hours count as fresh. Other prices may be older catalogue information. A blocked, unavailable or unverified listing is not automatically considered sold out. Check the retailer page before purchasing.

🔔 Set up Discord pings without spam

Choose which Shaqs Poke Stock alerts can buzz your phone. These settings are controlled in Discord, not on this website.

Recommended setup (about 1 minute)
  1. Join the Shaqs Poke Stock Discord and open the server.
  2. Open the server name or its notification/bell menu, then choose Notification Settings.
  3. Set server notifications to Only @mentions rather than All Messages.
  4. Enable Suppress @everyone and @here to avoid mass pings.
  5. For the stock-alert channel, open its notification settings and choose Only @mentions. Set chat and other busy channels to Nothing if you only want important alerts.
Important: If you want opted-in Stock Alerts or Price Drops role pings, do not enable “Suppress All Role @mentions” for the server. That setting can silence the role alerts you opted into.
iPhone and Android notification checks
  • iPhone: Settings → Notifications → Discord → allow notifications. Choose whether to show banners, sounds and lock-screen alerts.
  • Android: Settings → Notifications → App notifications → Discord. Allow notifications and check the relevant notification categories.
  • In Discord mobile, open the server's notification settings and make sure mobile push notifications are enabled.
Still getting too many pings?
  • Set channels you don't need to Nothing or mute them.
  • Keep routine conversation separate from opt-in stock/price alerts.
  • Role pings depend on alert type and configuration. Not every product check creates a notification; alerts should only be sent for qualifying verified changes.

📲 Add Shaqs Poke Stock to your home screen

Add a shortcut so the catalogue opens quickly like an app. No app-store download is required.

iPhone or iPad (Safari)
  1. Open this website in Safari.
  2. Tap the Share button (the square with an upward arrow).
  3. Scroll and tap Add to Home Screen. If shown, enable Open as Web App.
  4. Tap Add. Find the Shaqs Poke Stock icon on your home screen.
Android (Chrome)
  1. Open this website in Chrome.
  2. Tap the three-dot menu in the top-right.
  3. Tap Add to Home screen or Install app if offered.
  4. Confirm by tapping Add or Install.
Windows or desktop Chrome / Edge
  1. Open the website in Chrome or Edge.
  2. Use the browser's install option if offered, or create a shortcut from the browser menu.
Your watchlist and price targets are saved locally in that browser/device; they don't automatically sync to another phone or computer. Price targets are checked when the page loads or refreshes, not continuously while the site is closed.
